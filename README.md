# Supply Chain Lead Time Optimisation Using Machine Learning

## Overview
This project focuses on optimizing supply chain lead times using machine learning and simulation techniques. It analyzes Nassau Candy distributor data to predict delivery lead times, identify optimal factory assignments, and provide actionable business recommendations through an interactive dashboard.

## Objective
The objective of this project is to improve supply chain efficiency by predicting lead times and recommending better factory-to-region assignments using data-driven analysis.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Plotly
- Machine Learning

## Project Features
- Data preprocessing and feature engineering
- Lead time prediction using ML models
- Factory reassignment simulation
- Route clustering analysis
- Interactive Streamlit dashboard
- Business insights and recommendations

## How to Run
### Manual Run
1. Install required libraries:
   pip install -r requirements.txt

2. Run the dashboard:
   streamlit run app.py

## Easy Run Option (Windows)
For quick execution on Windows, double-click the `run_dashboard.bat` file included in this repository.  
This will automatically launch the project dashboard without manually entering commands.
